# Graham's ScriptArchive

An archive of 40 years of scripts.

The intention is to have these as definitive, and many projects have
hard links here. We don't use symlinks as github will record the
actual path to the file, usually as
/home/user/projects/scripts/feature/function which does not
generalise. Stay with hard links.
